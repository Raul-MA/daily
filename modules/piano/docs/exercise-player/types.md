# Exercise application types

Generated by `node scripts/piano-player-contract.mjs` from the runtime schema. Daily is plain JavaScript: the schema and validator enforce these matching structural types at import and storage boundaries. These declarations are documentation, not a TypeScript build dependency. Numeric bounds and cross-field invariants are enforced by the validator.
